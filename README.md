# 마인드 리와이어 (Mind Rewire) — 나를 다시 배선하는 6스텝

HR 분야 성인 대상 **The Science of Self-Improvement 프로그램** (교재: *The Science of Self-Improvement*, Steven Handel).
생각·감정·습관·일·관계·몸을 한 챕터씩 함께 실습하고, 서로의 결과를 실시간 차트로 확인하는 인터랙티브 사이트입니다.

## 구성

| 스텝 | 교재 챕터 | 실습 | 결과 도표 |
|---|---|---|---|
| 1 | 믿음과 현실 지도 | 믿음 점검 · 리프레임 · 12가지 편향 진단 · 프레이밍 실험 · 긍정:부정 | 편향 레이더, 편향 Top, 믿음 전·후, 프레이밍(교재 72%/22% 비교), 3:1 기준선 |
| 2 | 감정 지능 | 5축 진단 · 감정 기록 · 비판단 서술 · 직관 실험 · 조절 도구 | 감정 지능 레이더, 감정 분포, 감정별 강도, 영향 요인, 관찰 전·후, 도구 레이더 |
| 3 | 습관 바꾸기 | 습관 루프 · if-then · 의지력 · 불안 사다리 · 한 주 실험 | 신호/보상 분포, 습관 수, 불안 사다리, 달성일, 평가 레이더 |
| 4 | 일과 여가 | 일 만족 8축 · 시간 지도 · 휴식 처방 | 만족 레이더, 시간 도넛, 휴식 비율, 비율 vs 만족도 산점도, 지치는 시간대 |
| 5 | 긍정적 관계 | 관계·소통·원칙 점검 · 대화 스레딩 · 관계 에너지 지도 | 레이더 2종, 소통 막대, 관계 에너지 도넛/누적 막대 |
| 6 | 몸과 마음 + 결론 | 뇌 식단 · 움직임 · 컨디션 · 건강 실험 · 12원칙 선택 | 식단 막대, 앉기 vs 운동 산점도, 컨디션 레이더, 원칙 Top |
| 종합 | — | — | 리와이어 지수 레이더(6축), 지표 바, 스텝별 완성도, 참가자 진행 매트릭스 |

각 스텝은 왼쪽 **실습**, 오른쪽 **실시간 결과**(내 결과 + 참가자 비교 + 함께 나눈 답변)로 구성되며 입력하면 자동 저장됩니다.
`공유` 표시가 있는 항목만 "함께 나눈 답변"에 보입니다. 종합 화면에서 내 답변을 `.md`로 저장하거나 인쇄/PDF로 내보낼 수 있습니다.

## 실행 방법

빌드가 필요 없는 정적 사이트입니다.

- GitHub Pages: 저장소 **Settings → Pages → Deploy from a branch → `main` / `(root)`**
- 로컬: 폴더에서 `python3 -m http.server` 후 `http://localhost:8000`
- 수강생 초대: `https://<계정>.github.io/self_improvement/?room=세션코드`

## 모드

### 1) 데모 모드 (기본)
`js/config.js`의 `firebaseDatabaseURL`이 비어 있으면 결과가 **그 브라우저에만** 저장되고 샘플 참가자 8명이 채워집니다.

### 2) 실시간 공유 모드 (수업용)
1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기
2. **Build → Realtime Database → 데이터베이스 만들기**
3. **규칙(Rules)** 탭에 아래 내용을 붙여 넣고 게시
4. `js/config.js`의 `firebaseDatabaseURL`에 데이터베이스 주소를 넣고 커밋

```json
{
  "rules": {
    "mind-rewire": {
      "rooms": {
        "$room": { ".read": true, ".write": true }
      }
    }
  }
}
```

> 세션 코드를 아는 누구나 읽고 쓸 수 있습니다. 개인 정보·민감한 내용은 쓰지 않도록 안내하고, 수업이 끝나면 `mind-rewire`를 삭제하거나 규칙을 `false`로 바꾸세요. 닉네임만 사용합니다.
